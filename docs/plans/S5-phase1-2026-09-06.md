## ADR Review

**ADR-0021 (Thoth-native architecture) — APPLICABLE, in full.** Governing rules for this story:
- The in-session hook gate is implemented only through Claude Code's documented `PreToolUse`, `UserPromptSubmit`, `SessionStart`, `SubagentStop` primitives; `SessionStart` alone cannot halt a session — the halt point is `UserPromptSubmit` (gap G5).
- The hook calls S2's `decide()` directly — one kernel build artifact, no second decision path (POL-03).
- The hook script is the impure shell; it imports the kernel, the kernel never imports it (POL-11).
- No new normalizer is added by editing a shared dispatch chain or the kernel (POL-12) — S5 calls the existing registry.
- The normalizer never verdicts; the kernel never inspects a tool's identity/shape directly (§3.2) — the hook does the `tool_name → toolType` mapping.
- No `@microsoft/agent-governance-*` import anywhere in S5.

No other ADR (devops or software-engineering) governs this diff surface.

## 1. Story, restated

Wire the already-shipped pure kernel (S2), normalizer registry (S3), and shell-command detector (S4) to Claude Code's real hook primitives on this repo's own `.claude/settings.json`, so a live `Bash` tool call is actually evaluated and can actually be denied — and close every other SUR item Milestone #23 names (SUR-02/03/05/10/11/12/13/14, OPS-03, T11) as the mechanism goes live for the first time (0% → real exposure).

## 3. Named findings (all ratified by the Manager, 2026-09-06 — see `docs/decisions.md`)

1. **No live tool-enumeration API exists** (confirmed against Claude Code's own docs/community sources; anthropics/claude-code#6574 open). SUR-03's enumeration is derived from static config: vendored built-in snapshot ∪ configured MCP servers (currently none, per this repo's own `.claude/settings.json`). A future MCP server whose tools can't be statically enumerated counts as unclassified/fail-closed.
2. **Live matcher scope is `Bash` only.** Routing other mutating built-ins (`Edit`/`Write`/`MultiEdit`/`NotebookEdit`) through today's registry would deny them unconditionally (no filesystem normalizer exists) — breaks ordinary file editing, including this repo's own. Filesystem-normalizer gap goes to `docs/backlog.md`.
3. **§0.4 tension ships, disclosed.** The bootstrap `RuleSet` is a normal, session-writable file (S6 hasn't shipped) — doesn't yet meet §0.4's "policy source unreachable by the governed session" bar. Ratified per §0.2's own corollary ("in-session gates are fast-feedback, not a security boundary") and §0.3 ("own it, don't oversell it") — same disclosed-gap-now pattern as every prior story. The bootstrap ruleset's file header states this plainly.

## 5. Plan

**Spike first (T11, PRINCIPLES rules 17/18 — not invented, not skippable):**
1. Corpus: S4's shell fixture/mutation corpus + explicit worst-case constructions (depth-cap-5 wrapper nesting, long multi-target commands).
2. Measure `normalize("shell", raw)` + `decide(worldFacts, action)` wall-clock (`process.hrtime.bigint()`, ≥1000 iterations) → p50/p95/p99.
3. Confirm Claude Code's own documented default command-hook timeout (600s absent an explicit `timeout` key — NOT AGT's 30s, a different vendor's number) and that `timeout` is per-entry configurable with no documented ceiling below that default.
4. Declared `timeout` = safety-margined multiple of measured p99; record methodology + number in `docs/spikes/` + a `docs/decisions.md` row (T11, closed).

**New files:**
- `hooks/pretooluse-kernel-gate.mjs` — matcher `Bash` only; stdin → `ShellCall` → `normalize` → `decide` → `hookSpecificOutput.permissionDecision`. Every SUR-10 fail-open path explicit: try/catch whole body, exit 2 + stderr on internal exception (never bare exit 1); malformed/missing `tool_input.command` → unresolved/deny, not a crash.
- `hooks/sessionstart-tool-enum.mjs` — computes real tool universe via shipped classification catalog; on `haltRequired`, writes a gitignored, `session_id`-correlated halt-state file.
- `hooks/userpromptsubmit-halt-relay.mjs` — reads halt-state for current `session_id`; exit 2 (blocks/erases prompt) if set, else 0. Built as a reusable halt-relay primitive (S11b plugs in a second halt reason later).
- `src/policy/config/bootstrap-ruleset.ts` — minimal `RuleSet` (`defaultOutcome: "deny"`), §0.4-placeholder disclosure in the file header.
- `src/policy/tools/builtin-tool-inventory.ts` + `docs/qa/tool-inventory.json` — real, cited, vendored snapshot (source URL + date, QA-17's discipline), replacing the 3-entry fixture as the real shipped-defaults layer.
- `src/qa/gate-matcher-drift-check.ts` (SUR-05) — same shape as `runtime-settings-drift-check.ts`.
- `src/qa/gate-manifest-check.ts` (SUR-13) — exactly one `hooks`-key-defining file.
- `src/policy/kernel/subagent-non-escalation.test.ts` (SUR-14, fixture-only).
