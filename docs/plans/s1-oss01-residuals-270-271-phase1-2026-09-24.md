## 3. Design

### 3a. #270 — derive scope and position, test-only

Change in `src/secret-scan/patterns.test.ts` only (no production code, no `patterns.ts` type change).

1. Replace the hand-written `VALUE_CLASS_EXEMPLARS` with a **registry that must cover the catalog**: `Record<patternId, { kind: "free-form"; prefix: string; value: string; suffix: string } | { kind: "ascii-only"; reason: string }>`.
   - `free-form` (today: `generic-password-assignment`, `private-key-block`): the exemplar is `prefix + value + suffix`; `value` is the region a high byte must not hide.
   - `ascii-only` (the other 8): a one-line reason (fixed alphabet, e.g. `aws-access-key-id` is `[0-9A-Z]{16}`).
2. Scope is **mechanical**: a pure `uncoveredPatternIds(patterns, registry)` returns ids present in `SECRET_PATTERNS` but not in the registry, and ids in the registry but not in the catalog. The named test asserts both lists are empty. Adding an 11th pattern fails the suite until its author declares free-form or ascii-only, so evasion shape 7 (a pattern never swept) is impossible by construction.
3. Position is **mechanical**: for each `free-form` entry, replace each character of `value` in turn (positions `0..value.length-1`) with each byte `0x80-0xFF`, and require `exec(text)[0] === text` (same predicate as today). Replacement, not insertion, so a `{8,}` minimum is not disturbed. First and last characters are covered (shapes 5, 6). Cell count = `sum(value.length * 128)`, printed by the test, not typed anywhere.
4. Non-vacuous controls, named, run through the same function: first-only narrowing, last-only narrowing (both built by substituting the shipped class token, as the existing positive control does), and a synthetic 11th pattern absent from the registry. Each control must fail the checker; the shipped catalog must pass.
5. Delete the hand-derived completeness prose at lines 320 and 355 (the editorial item in the red-team report).

Honest limit, stated in the test header: the `free-form` versus `ascii-only` classification is a declared judgment, forced and visible in any diff that adds a pattern, not a mechanical proof. What is now mechanical is that no pattern is unclassified and no position is skipped.

### 3b. #271 — content-addressed grant, deterministic unlock

1. `history-scan.ts:212`: hash input becomes `oss01-scan-timeout:${text}` (drop `pattern.id`). Introduce and export one function `scanTimeoutHash(text)` used by `scanBlobText` and by the tool, so the two cannot drift. `redacted` keeps `pattern=<id>` for the human (display only, not identity). Update the long #264 comment block with the #271 rationale (a paragraph, not a page).
2. `allowlist-tool.ts` `hashLines(text, "oss01-scan-timeout")`: no scan. Return one line `${scanTimeoutHash(text)}  …[SCAN-TIMEOUT bytes=${text.length}]`. `runHash` already unions over `decodeBlobVariants`, so a BOM'd blob prints one hash per variant, as the gate can report.
   - Effect: the unlock prints the identical hash set on every machine, whether or not this machine's clock trips. A hash for a blob that does not time out locally is harmless (a grant for text that scans fully is an entry that matches nothing, already disclosed as Issue #235).
3. Fail-safe direction unchanged: a slow machine still blocks, a fast machine still scans fully, nothing silently passes.
4. Not changed: `SCAN_TIMEOUT_MS`, `matchAllBounded`, the loader, `partitionAllowlisted`, the allowlist JSON, `ci.yml`, `patterns.ts`.
5. **Residual, ratified in ADR row 111** (rewritten): the gate's red/green outcome for a blob near the boundary, and spurious timeouts under CPU contention (the 2026-09-23 debug report), are still a wall-clock race. Effect: an occasional false block (never a false pass), and a granted blob passes either way. The only true fix is a deterministic engine (RE2 lacks the lookahead `internal-hostname` uses; a step-budget engine is a rewrite). That goes to `docs/backlog.md` or a new Issue at the Manager's choice (PRINCIPLES rule 12); it is not in this diff.
6. ADR row 110 also carries a hand-typed "eight real patterns" claim (the catalog has 10); rewrite the sentence without the number.
